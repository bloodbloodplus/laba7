# Домашнее задание к работе 2

## Условие задачи

Составить программу, которая по названию фигуры (**треугольник — `t`, квадрат — `s`, круг — `o`, прямоугольник — `r`**) вычисляет площадь этой фигуры. Необходимые значения задаются пользователем.

---

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало программы.**
2. Подключить необходимые библиотеки и установить русскую локализацию.
3. Объявить переменные:
   - `figura` — выбранная геометрическая фигура;
   - `a`, `b` — размеры фигуры;
   - `s` — площадь фигуры.
4. Вывести список доступных фигур и предложить пользователю выбрать нужную.
5. **Ввести букву**, соответствующую выбранной фигуре.
6. Выполнить проверку выбора с помощью оператора `switch`.
7. Если выбрана буква **`t` (треугольник)**:
   - запросить основание и высоту;
   - вычислить площадь по формуле `s = a * b / 2`;
   - вывести результат.
8. Если выбрана буква **`s` (квадрат)**:
   - запросить длину стороны;
   - вычислить площадь по формуле `s = a * a`;
   - вывести результат.
9. Если выбрана буква **`o` (круг)**:
   - запросить радиус;
   - вычислить площадь по формуле `s = 3.14159 * a * a`;
   - вывести результат.
10. Если выбрана буква **`r` (прямоугольник)**:
    - запросить длину и ширину;
    - вычислить площадь по формуле `s = a * b`;
    - вывести результат.
11. Если введена неизвестная буква, вывести сообщение **«Такой фигуры нет!»**.
12. **Конец программы.**
